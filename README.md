## 🚀 Overview

ResumeBoostAI helps users improve their resumes by leveraging **Google Gemini AI** to analyze uploaded resumes, generate ATS-style scores, identify strengths and weaknesses, and provide practical suggestions for improvement.

---

# ✨ Features

- 📄 Upload Resume
- 🤖 AI-powered Resume Analysis
- 📊 ATS Score Generation
- 💪 Strength & Weakness Detection
- 💡 Personalized Improvement Suggestions
- 📚 Resume History
- 📑 Resume Comparison

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/aravindkumar-2026/ResumeBoostAI.git
```

Move into the project

```bash
cd ResumeBoostAI
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the development server

```bash
npm run dev
```

# 📖 How It Works

### 📄 Resume Upload

The user uploads a resume through the web interface.

⬇️

### 🤖 AI Analysis

The uploaded resume is sent securely to **Google Gemini AI**.

⬇️

### 📊 ATS Evaluation

The AI evaluates the resume and generates an ATS-style score.

⬇️

### 💡 Smart Suggestions

The application identifies:

- Strengths
- Weaknesses
- Missing Skills
- Improvement Suggestions

⬇️

### 📈 Results Dashboard

The user receives a detailed report with actionable feedback.
