# 🚀 ResumeBoostAI

An AI-powered Resume Analyzer that evaluates resumes using ATS (Applicant Tracking System) principles, identifies missing keywords, provides intelligent suggestions, and compares resumes against job descriptions to help job seekers improve their chances of getting shortlisted.

---

## 📖 Overview

ResumeBoostAI is designed to help students, fresh graduates, and professionals optimize their resumes before applying for jobs. It automatically analyzes uploaded resumes, calculates an ATS score, identifies strengths and weaknesses, and provides actionable recommendations for improvement.

The application also allows users to compare their resume with a job description to determine how well it matches the employer's requirements.

---

## ✨ Features

### 📄 Resume Upload
- Upload resumes in PDF or DOCX format.
- Automatic text extraction from uploaded files.
- Secure and fast processing.

### 📊 ATS Score
- Generates an overall ATS score out of 100.
- Evaluates resume quality based on multiple factors.

### 📈 Section-wise Analysis
Analyzes individual resume sections including:
- Skills
- Experience
- Education
- Projects
- Certifications
- Formatting
- Grammar

### 🧠 AI Suggestions
Provides intelligent recommendations to improve:
- Resume summary
- Project descriptions
- Work experience
- Action verbs
- Achievement statements
- Keyword usage

### 🔍 Skill Detection
Automatically identifies technical and soft skills present in the resume.

Example:
- Java
- Python
- SQL
- React
- Node.js
- Git
- HTML
- CSS

### ❌ Missing Keywords
Highlights important keywords that are absent from the resume but commonly expected by recruiters.

Example:
- AWS
- Docker
- Kubernetes
- REST API
- CI/CD
- Linux

### 💼 Job Description Matching
Compare a resume with a job description to:
- Calculate compatibility percentage
- Display matched skills
- Show missing skills
- Suggest improvements for better alignment

### 📋 Resume Report
Generate a detailed analysis report including:
- ATS Score
- Section Scores
- Strengths
- Weaknesses
- AI Recommendations

### 📱 Responsive Design
Works seamlessly across:
- Desktop
- Laptop
- Tablet
- Mobile devices

## ⚙️ How It Works

1. Upload a resume (PDF/DOCX).
2. Extract text from the document.
3. Analyze resume sections.
4. Calculate ATS score.
5. Detect existing skills.
6. Identify missing keywords.
7. Generate AI-powered suggestions.
8. Compare against a job description (optional).
9. Display analytics dashboard.
10. Download the analysis report.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ResumeBoostAI.git
```

Navigate to the project:

```bash
cd ResumeBoostAI
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
